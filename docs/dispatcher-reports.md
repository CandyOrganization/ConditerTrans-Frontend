# Отчёты диспетчера

Доступ: роль **Dispatcher**, раздел **Отчёты** в шапке (`/reports`).

## 1. Статистика отказов

- **API:** `GET /api/orders/dispatcher/reports/refusals?dateFrom=&dateTo=`
- Учитываются заказы со статусом **Rejected** производственной компании диспетчера.
- Период — по дате записи в истории (`order_change_histories`) при переходе в «Отклонён».
- Группировка по тексту причины (комментарий при отказе).
- В ответе: причина, число заказов, доля %.

## 2. Рейтинг продукции

- **API:** `GET /api/orders/dispatcher/reports/product-rating?dateFrom=&dateTo=`
- Учитываются только заказы со статусом **Confirmed**.
- Период — по `creation_date` заказа.
- Ранжирование товаров по количеству заказов, в которых товар присутствует.

Формат дат: `YYYY-MM-DD`. Пустые даты — без ограничения по соответствующей границе периода.
